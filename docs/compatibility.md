# Compatibility

Since v0.50.0, Surreal ORM Lite uses the official SDK 3.0, `surrealdb[pydantic]>=3.0.0,<4.0.0`, and supports exactly
the SurrealDB versions that SDK supports: the 2.x, 3.x and 4.x lines. The SDK 2.0 line (`0.40.x`) is deprecated and
receives security fixes only; move to `0.50.x` ([migration note](migrating-to-0.50.md)), or pin
`pip install "surreal-orm-lite<0.50"` if you must stay on SDK 2.0.

**Compatibility advantage over the full ORM**: ORM-lite runs on SurrealDB **2.x (2.6 / 2.7), 3.x (3.2 / 3.3) and 4.x
(4.0)**, while the full [SurrealDB-ORM](https://github.com/EulogySnowfall/SurrealDB-ORM/) (custom SDK) targets **3.x
only**. Lite stays usable on existing 2.x deployments without forcing a server upgrade.

## ORM behaviour: SurrealDB 2.x, 3.x and 4.x

Surreal ORM Lite runs on the three lines; some capabilities differ because they rely on server
features introduced in SurrealDB 3.x, or because SurrealDB 4.x changed them. On 2.x the ORM degrades gracefully. Capabilities not
listed behave the same on every line. The 2.x column was measured on 2.6.5 and holds unchanged
on 2.7.0. The 3.x column was measured on 3.2.4 and holds on 3.3.0, except where a row says
otherwise. The full suite and every divergence below were re-verified on both new versions.
