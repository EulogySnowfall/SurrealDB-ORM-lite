# v0.13.0 — `SurrealFunc` & `server_values=` / `extra_vars=` — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (chosen: inline,
> task-level checkpoints) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Let `save()` and `merge()` evaluate values **server-side**: a `SurrealFunc` marker
(+ `SurrealFunc.call` builder and six curated, dual-DB-verified function-name enums) inlines a
raw SurrealQL expression into a compiled `SET` clause, while every regular field value and
every `extra_vars` entry stays **bound** (anti-injection). Identical behaviour on SurrealDB
2.6.x and 3.x — no capability gate.

**Architecture:** New `functions.py` (no package imports → no cycle) holds `SurrealFunc` +
enums. `utils.py` gains the pure compilers `build_set_clause` / `merge_extra_vars`.
`model_base.py` routes `save(server_values=…)` to `CREATE $rid SET <clause>` (auto-id:
`CREATE <table> SET …`) and `merge(server_values=…)` to `UPDATE $rid SET <clause>` via
`client.query()` / `tx.add()`, keeping the existing signal envelopes and tx semantics.
The native SDK paths are untouched when `server_values` is absent.

**Tech Stack:** Python 3.11+, Pydantic v2, `surrealdb[pydantic]>=2.0.0,<3.0.0`, pytest +
pytest-asyncio. Dual-DB test harness: SurrealDB 3.1.3 (:8001) and 2.6.5 (:8002).

**Design spec:** `docs/superpowers/specs/2026-07-22-v0.13.0-surreal-func-design.md`

import pytest

from surreal_orm_lite.functions import SurrealFunc


class TestSurrealFunc:
    def test_wraps_and_strips_expression(self) -> None:
        f = SurrealFunc("  time::now()  ")
        assert f.expression == "time::now()"

    def test_rejects_empty_and_non_string(self) -> None:
        with pytest.raises(ValueError):
            SurrealFunc("")
        with pytest.raises(ValueError):
            SurrealFunc("   ")

    def test_rejects_statement_terminator(self) -> None:
        with pytest.raises(ValueError, match=";"):
            SurrealFunc("time::now(); REMOVE TABLE User")

    def test_call_renders_name_and_args(self) -> None:
        assert SurrealFunc.call("time::now").expression == "time::now()"
        f = SurrealFunc.call("crypto::argon2::generate", "$password")
        assert f.expression == "crypto::argon2::generate($password)"
        f2 = SurrealFunc.call("math::pow", "2", "3")
        assert f2.expression == "math::pow(2, 3)"

    def test_repr_eq_hash(self) -> None:
        a, b = SurrealFunc("time::now()"), SurrealFunc("time::now()")
        assert a == b and hash(a) == hash(b)
        assert "time::now()" in repr(a)
        assert a != SurrealFunc("rand()")
        assert (a == "time::now()") is False
```

from surreal_orm_lite.utils import build_set_clause, merge_extra_vars

class TestBuildSetClause:
    def test_binds_values_and_inlines_funcs(self) -> None:
        clause, variables = build_set_clause({"name": "Alice", "joined": SurrealFunc("time::now()")})
        assert clause == "name = $_sv_name, joined = time::now()"
        assert variables == {"_sv_name": "Alice"}

    def test_injection_shaped_value_stays_bound(self) -> None:
        evil = "x; REMOVE TABLE User;"
        clause, variables = build_set_clause({"bio": evil})
        assert evil not in clause and variables["_sv_bio"] == evil

    def test_invalid_key_raises(self) -> None:
        for bad in ("a b", "a;b", "a.b", "1a", ""):
            with pytest.raises(ValueError):
                build_set_clause({bad: 1})

class TestMergeExtraVars:
    def test_merges_and_guards_collisions(self) -> None:
        variables = {"_sv_name": "A", "rid": "r"}
        merged = merge_extra_vars(variables, {"password": "s3cret"})
        assert merged["password"] == "s3cret"
        with pytest.raises(ValueError, match="rid"):
            merge_extra_vars(variables, {"rid": "boom"})
        with pytest.raises(ValueError, match="_sv_name"):
            merge_extra_vars(variables, {"_sv_name": "boom"})
        assert merge_extra_vars(variables, None) is variables
```

## Task 4: `save(server_values=, extra_vars=)` — CREATE … SET

**Files:** Modify `src/surreal_orm_lite/model_base.py`; extend `tests/test_functions.py`.

- [ ] **Step 1: Write the failing tests** — validation unit tests + E2E (both ports): 1. `save(server_values={"joined_at": SurrealFunc.call(SurrealTimeFunction.NOW)})` with
      explicit id → instance & stored `joined_at` is a `datetime` (not the literal string);
      regular fields intact. 2. Same id twice → `SurrealDbError` (match "already exists"). 3. Auto-id + `server_values` (non-tx) → id assigned, func evaluated. 4. Argon2 + `extra_vars`: stored value starts with `$argon2` and
      `RETURN crypto::argon2::compare($h, $p)` is `True`; raw password not in the record. 5. `server_values={"joined_at": "not-a-func"}` → `TypeError`;
      `extra_vars` without `server_values` → `ValueError`;
      `server_values` key colliding shape (`"a b"`) → `ValueError`. 6. Signals: `pre_save`/`post_save` fire once around a server-values save. 7. Injection-shaped **value** in a regular field alongside `server_values` → stored
      literally (bound), table intact.

- [ ] **Step 2: Run to verify FAIL** — `TypeError: save() got an unexpected keyword argument`.

- [ ] **Step 3: Implement** — in `model_base.py`: - `save(self, tx=None, server_values=None, extra_vars=None)`:
      `extra_vars and not server_values` → `ValueError`; if `server_values` →
      `functools.partial(self._do_save_server, server_values=server_values,
      extra_vars=extra_vars)` through the existing `_save_with_signals`; else unchanged. - `_validate_server_values(server_values)`: every value `isinstance SurrealFunc` else
      `TypeError` (key validation happens in `build_set_clause`). - `_do_save_server(tx=…, server_values=…, extra_vars=…)`: merged =
      `{**model_dump(exclude={"id"}), **server_values}`; `build_set_clause` →
      `merge_extra_vars`; explicit id → `CREATE $rid SET <clause>;` (`rid` bound); auto-id →
      validate `get_table_name()` with `validate_field_name(table, "table name")` then
      `CREATE {table} SET <clause>;`. tx: buffered + auto-id → the existing explicit-id
      error; `tx.add(stmt, vars)` → `_apply_record` (interactive applies; buffered no-op).
      Non-tx: `client.query`, already-exists `ServerError` normalised to `SurrealDbError`
      (same wording as `_do_save`), `_apply_record(rows)`. Returns `(self, True)`.

- [ ] **Step 4: Run on both ports** — `dual_db_test.sh -k "test_functions and save"` → PASS ×2.
